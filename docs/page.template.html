Abstract

A draft model that lives inside the target's weights

Speculative decoding needs a cheap draft model, and keeping a separate one costs memory. BitNest embeds a low-precision draft inside the higher-precision target weights. A single 8-bit tensor serves both: the target reads all 8 bits, the draft reads only the high 4 bits. Rather than truncating an 8-bit model, BitNest first builds a strong low-precision foundation and then recovers the higher precision through a residual refinement. The same nesting extends to the KV cache for long contexts. Across 7B–8B models, BitNest reaches an average speculative acceptance rate of 95.2% and a 1.48–1.61× end-to-end speedup over FP16 autoregressive decoding.

Method

One byte, two models

Every weight is stored as an 8-bit code split into two 4-bit planes. The draft streams only the high plane, so a draft step moves half the bytes of a target step.

Step 1 · rotate

Remove outliers

Learned rotations (SpinQuant) are fused into the weights so that 4-bit quantization is accurate.

Step 2 · fit the draft

GPTQ at 4 bits

The 4-bit model is fitted first with GPTQ and locked as the high nibble, so the draft is a strong model in its own right.

hi = q4 = GPTQ-W4(W)
Step 3 · refine

Residual back to 8 bits

The low nibble rounds the remaining residual on a 16× finer grid, recovering 8-bit quality in closed form.

lo = qr = round((W − q4·s) / (s/16))

Decoding

The draft proposes γ tokens one at a time reading only the high planes; the target then checks all of them in a single batched pass reading both planes and keeps the longest prefix it agrees with, plus one token of its own. The output is the target's greedy output. The KV cache is nested the same way: the draft attends over 4-bit keys and values, the target over 8-bit ones, from one cache. Dual-plane GEMM and attention kernels are written in Triton, and every step runs as a captured CUDA graph.
